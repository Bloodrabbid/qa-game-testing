# qa-game-testing

Скилл для Claude: тестирование видеоигр (ПК, консоли, мобайл, веб) — тестирование по стадиям билда, 13 типов игровых багов и severity, производительность (FPS, frame time, 1% Low, input lag, bottleneck CPU), установка, обновление и сохранения, мобильные прерывания и жизненный цикл, HUD, звук, локализация, доступность, игровой баг-репорт и автоматизация.

Методика — по руководству Романа Суркова «Качество решает всё: полное руководство по тестированию ПО». Скилл — сжатый пересказ своими словами; то, чего в книге нет, помечено **[вне книги]**.

Общая база (тест-дизайн, артефакты, API): [qa-software-testing](https://github.com/Bloodrabbid/qa-software-testing).

## Установка

Скопируй `SKILL.md` в папку скиллов Claude (например, `~/.claude/skills/qa-game-testing/SKILL.md`) или загрузи в настройках Claude.
